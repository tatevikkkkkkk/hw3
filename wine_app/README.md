# 🍷 Wine selection app (ДЗ-3)

Streamlit-приложение для отбора «хороших» вин (оценка ≥ 7) по лабораторным показателям.
Модель — `StandardScaler` + `LogisticRegression`, порог `0.27` (максимум F1 на валидации).
Модель внутри приложения не обучается: используются сохранённые `model.joblib`, `config.json`, `test.csv`.

## Запуск локально

Версия Python: **3.13** (проверено на 3.13.7).

```bash
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется на http://localhost:8501.

## Вкладки
1. **Оценка одного вина** — ввод 12 признаков, вероятность и решение при пороге из сайдбара.
2. **Модельные метрики** — матрица ошибок, precision/recall/F1, ROC- и PR-кривые с точкой текущего порога.
3. **Пакетное предсказание** — загрузка CSV, таблица с вероятностями и решениями, скачивание результата.
4. **Что выучила модель** — коэффициенты логистической регрессии.

## Почему `st.cache_resource` для модели и `st.cache_data` для таблиц
`st.cache_resource` хранит один объект на весь сервер и отдаёт его всем сессиям без копирования —
это подходит для модели (тяжёлый объект, который мы не меняем). `st.cache_data` сериализует результат
и каждый раз отдаёт копию — это подходит для данных (DataFrame, массивы вероятностей), чтобы изменение
таблицы в одном месте не испортило кэш. Если вызывать `joblib.load` без декоратора, модель будет заново
читаться с диска при каждом действии пользователя (например, при каждом движении слайдера), потому что
Streamlit перезапускает весь скрипт сверху вниз.
